# Terms of Use

`AvaAgent` is provided as a local software tool for wallet operations and swap execution.

## Use at your own risk

- blockchain transactions are irreversible
- users are responsible for validating recipient addresses, token contracts, and swap parameters
- users should test on low-value or testnet wallets before handling meaningful funds

## No warranty

This project is provided on an as-is basis without guarantees of fitness, uptime, or trading outcomes.

## Safety expectations

- do not rely on unreviewed AI prompts for fund movement
- require explicit user approval before state-changing actions
- use the configured safety caps where appropriate
